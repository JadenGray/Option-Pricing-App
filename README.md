# Option Pricing App
A streamlit web app to calculate and visualise European options pricing and Greeks using Black Scholes. To access the app, visit https://optionpricingapp.streamlit.app/. 

# Functionality

## Option Calculations
Input option parmeters into the sidebar and calculate its theoretical price, implied volatility or greeks. 
![alt text](screenshots\image.png)

## Heatmaps
Generate pnl or Greek heatmaps to visualise how these change with spot price and market volatility for a given option
![alt text](screenshots\image-1.png)

## Option Portfolios
Analyse portfolios consisting of multiple options using the same heatmaps, or look at the theoretical pricing plot of the portfolio to visualise how it changes with spot price. 
![alt text](screenshots\image-2.png)
